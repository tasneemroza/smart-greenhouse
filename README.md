# Smart Greenhouse

A Smart Greenhouse application developed as a course project.

The project is currently focused on building the foundation of the system. The first phase includes the backend setup, PostgreSQL database connection, Alembic migrations, and the React frontend.

## 1. What the project is

The Smart Greenhouse project is designed to provide a foundation for monitoring and controlling a greenhouse.

In this phase, the project contains:

- FastAPI backend
- PostgreSQL database
- Alembic database migrations
- React + TypeScript frontend
- React Router
- Tailwind CSS v4

The actual greenhouse devices, sensors, automation and other business functionality will be implemented in later phases.

## 2. Prerequisites

The following software is required:

- Python 3.12 or newer
- Node.js
- npm
- Docker Desktop
- Git
- PostgreSQL through Docker
